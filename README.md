# Projetos_Dados 📊
Repositório para documentar projetos em Análise de dados utilizando Bibliotecas python.

## Projeto 1 - Projeto de ETL em arquivos CSV. 🏬

 - **Objetivo**: Simular um cenário onde uma empresa recebe **relatórios de vendas mensais em CSV**, cheios de pequenas inconsistências como  da dados nulos, duplicados, texto com espaços e preços em formatos diferentes e Realizar o tratamento e postagem desses dados.
 - **Tecnologias Utilizadas** : **Pandas** | **SQLAlchemy** | **Matplotlib**
